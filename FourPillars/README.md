# FourPillars

[![Build Status](https://img.shields.io/badge/status-under_construction-yellow.svg)]()
[![License](https://img.shields.io/badge/license-MIT-blue.svg)]()

A modern .NET base library for traditional Chinese Four Pillars (Bazi) calculation and analysis.

> ⚠️ ​**This library is currently under active development**  
> API interfaces and core models are stabilizing but may still undergo changes. Not recommended for production use yet.

## Features (Planned)

- [x] Core models for Heavenly Stems and Earthly Branches
- [x] Basic Four Pillars chart calculation
- [ ] Advanced analysis modules:
  - [ ] Five Elements (Wu Xing) analysis
  - [ ] Ten Gods (Shi Shen) relationships
  - [ ] Deities (Shen Sha) calculation
- [ ] Lunar calendar support
- [ ] Luck cycle (Da Yun) calculation
